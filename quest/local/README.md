# Local PR backlog

## Goal

The open pull requests that still need a landing step, a review, a conflict fix, or a decision are planned in this tree in effort order, split into session-sized steps. This directory is local only: it is not claimed, and its branch is not pushed.

## Plan

Numeric prefixes keep the backlog order (easy, then large, then slow). A letter suffix is one session: one goal, a few files, and an exact success check. `## Required` unlocks the next step in that group when the earlier file is removed. A quest that already has a draft continues on that pull request; it does not open a second claim. Merges into an upstream pull request branch, a description posted under the owner's name, marking a draft ready, closing a pull request, and design calls are person actions, not coding sessions.
