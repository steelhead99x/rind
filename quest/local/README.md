# Local PR backlog

## Goal

The open pull requests that still need a landing step, a review, a conflict fix, or a decision are planned in this tree in effort order, from the smallest remaining actions to the work that waits on a design call or a failing test. This directory is local only: it is not claimed, and its branch is not pushed.

## Plan

Numeric filename prefixes are the order of work. A quest that already has a draft continues on that pull request; it does not open a second claim. Merges into an upstream pull request branch, a description posted under the owner's name, marking a draft ready, and closing a pull request wait on an explicit go.
