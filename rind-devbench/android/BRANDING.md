# RindBench brand assets

The toolbar uses the app's existing Rind mark, a compact rendition of the
[project logo](https://github.com/kixel-ai/rind/blob/main/admin/logo.png).
Rind green identifies controls and active navigation.

The flight-display palette uses [Kixel's](https://kixel.ai/) graphite and
amber in the display surfaces and timing readout. The Details sheet uses
the [Kixel favicon](https://kixel.ai/favicon.svg), rasterized for Android,
beside the line "rind by Kixel AI": the APK is built from this fork of
Kixel's rind, so the line names the project rather than giving Kixel AI as
its publisher. The day palette adapts the same roles for light surfaces.

The iPad and iPhone app use the Android night palette and the same Rind
and Kixel marks in the header, beside the same "rind by Kixel AI" line,
and keep the footer saying the app is an unofficial community tool. The
iOS launcher icons use the Android launcher art. The Rind website uses
both palettes, the Rind peel mark in its header, the wordmark on its
social card, and the same Kixel mark.
