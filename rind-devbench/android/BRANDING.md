# Android brand assets

The toolbar uses the app's existing Rind mark, a compact rendition of the
[project logo](https://github.com/kixel-ai/rind/blob/main/admin/logo.png).
Rind green identifies controls and active navigation.

The flight-display palette uses [Kixel's](https://kixel.ai/) graphite and
amber in the display surfaces and timing readout. The Details sheet uses
the [Kixel favicon](https://kixel.ai/favicon.svg), rasterized for Android,
beside the publisher name. The day palette adapts the same roles for
light surfaces.

## Permission

The Kixel mark and name are Kixel's. This app is built and signed from the
steelhead99x fork, under the `io.github.steelhead99x` package, so the Details
sheet credits the project ("rind by Kixel AI") rather than naming a
publisher. Using the mark still needs Kixel's (Luke's) written permission,
which this fork doesn't have yet: get it before this ships, and record it
here.

## Choices to note

- Android 12's dynamic colour (Material You) is off: the app always uses this
  palette, so the brand reads the same on every phone.
- Failure states ("Could not load tests", "Could not start", "Nothing
  picked") use the theme's error colour, not Rind green.
- The iOS bench isn't rebranded yet, so the two apps look different.
